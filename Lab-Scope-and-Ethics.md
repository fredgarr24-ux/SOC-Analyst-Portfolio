# Lab Scope and Ethics

## Objective

To build a safe, controlled cybersecurity laboratory for practicing networking, system administration, security monitoring, and incident investigation.

## Authorized Systems

I will practice using my own computer, virtual machines, and systems I have explicit permission to access.

## Planned Activities

- Network configuration and troubleshooting
- Windows and Linux administration
- Active Directory deployment
- Network traffic analysis
- Security event monitoring
- Vulnerability assessment
- Threat intelligence
- Incident investigation

## Safety Rules

1. I will not test systems without authorization.
2. I will use isolated laboratory networks where appropriate.
3. I will not publish passwords, access tokens, or sensitive personal information.
4. I will record my activities and findings honestly.
5. I will follow applicable laws and responsible disclosure practices.

## Expected Outcome

A documented and repeatable cybersecurity laboratory that supports practical SOC Analyst training.
